# Исправления Joy-Con для Eden

Экспериментальный патч раздельной HD-вибрации и встроенной ИК-камеры правого Joy-Con.
Изменения работают в драйвере эмулятора; привязки к конкретной игре нет. Проверяли прежде всего 1-2-Switch и оригинальные Nintendo Joy-Con по Bluetooth. Совместимость всех других игр и режимов ИК-камеры не подтверждена.

## Установка

Бинарный патч подходит только к точному Windows x64 exe Eden v0.2.1. Поддерживаемые SHA256 перечислены в [основной инструкции](README.md#exact-binary-compatibility). Другие сборки программа отклоняет.

Установите Python 3.10+ и распакуйте репозиторий. Откройте PowerShell в его папке:

```powershell
python -m pip install -r requirements.txt
python patch_joycon.py "C:\Emulators\Eden\eden.exe" --check
python patch_joycon.py "C:\Emulators\Eden\eden.exe" "C:\Emulators\Eden\eden.fixed.exe"
```

Подставьте свой путь. Программа создаёт отдельный файл; исходный exe сохраняется.
Закройте Eden, сохраните резервную копию `eden.exe`, затем замените его полученным файлом,
переименовав `eden.fixed.exe` в `eden.exe`. Оставьте остальные файлы установки рядом.

После этого запускайте Eden и игры как обычно: отдельные скрипты, Python и Frida для игры не нужны.
Для отката при закрытом эмуляторе верните резервный exe. Обновление Eden может заменить патч.

Для камеры нужен оригинальный правый Joy-Con с его встроенным ИК-сенсором.
Проверенная раскладка: игрок 1 — одиночный левый, игрок 2 — одиночный правый Joy-Con,
нативный драйвер Eden. Вибрацию проверяли в «Сколько шариков», камеру — в Eating Contest.
Мигание ИК-подсветки само по себе не подтверждает распознавание рта.

Подробности изменений, исходный C++ diff и команды проверки: [README](README.md).
Точные результаты и ограничения: [validation](docs/validation.md).
